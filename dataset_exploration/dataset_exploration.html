Dataset Description

The dataset was independently collected from the ÖSKB Results Service using an API interface and subsequently preprocessed. It contains detailed information about male and female players competing in the national leagues, as well as their scores over the past four years, including information about when and where the games took place.

Loading and Preprocessing the Dataset

data <- read.csv("https://raw.githubusercontent.com/nikolimaj/oeskb_dashboard/master/parsed_data/game_data_latest.csv", row.names = NULL, stringsAsFactors=TRUE)

data <- data %>%
  mutate(heim = ifelse(heim == "True", TRUE, FALSE)) %>%
  mutate(datum = as.Date(datum, format="%Y-%m-%d")) %>%
  filter(
    # remove extreme outliers (probably coming from players giving up mid game)
    kegel > quantile(kegel, 0.001, na.rm = TRUE) - 1.5 * IQR(kegel, na.rm = TRUE)
  )
